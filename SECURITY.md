# Security policy

This policy applies to every public repository of [GUELORD-MWENDERWA](https://github.com/GUELORD-MWENDERWA) that does not have its own.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Write to **guelsmwenderwa@gmail.com** with:

- the repository and, if possible, the file or endpoint concerned;
- what an attacker could do, and the steps to reproduce it;
- the version or commit you tested.

You will receive an answer within seven days. Once the problem is confirmed, a fix is prepared before any public disclosure, and you are credited if you wish.

## Supported versions

Only the latest commit of the default branch of each repository receives security fixes.
